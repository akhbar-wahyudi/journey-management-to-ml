# Semester 1 Reflection

*Written: November 2026*

## The challenge
My time is limited. Studying ML on my own is very different from studying
at university: nobody sets a schedule, so everything depends on me, and
sometimes I feel lazy, sleepy, or tired. Doing both coursework and
self-study, with all the writing done by hand on paper, is exhausting.


## My starting point
I'm still learning ML theory on paper. I haven't yet applied it in code
(Python) or built a working ML model.
  
## First strategy 
"write first, explain later"

The goal is to get the material down first, then explain it in my own
words afterward.

- Get the content first. The source can be a textbook, lecture notes,
  or an AI summary. What matters is that the material is in front of me.
- Explain it myself second. I then condense it in my own words onto
  one sheet of paper, so I know I actually understand it.
- Why it saves time: I no longer copy the full material by hand and
  then summarize it again, which would mean writing everything twice.
  Starting from ready-made text lets me spend my effort on understanding
  instead of copying.
- For ML theory: I study algorithms (decision trees, support vector
  machines, linear regression) manually on paper.

## What I'm unsure about
- Will learning algorithms only on paper be enough, or when should I start coding them?
- How do I keep this routine going when I'm tired?
